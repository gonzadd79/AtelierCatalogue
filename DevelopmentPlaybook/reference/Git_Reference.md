# Git Reference

Le Git Reference déclare le périmètre canonique réservé aux conventions Git du Framework.

## Reference Charter

- **Status:** Planned
- **Purpose:** Établir et maintenir des conventions cohérentes pour enregistrer, organiser et partager les évolutions du Framework avec Git.
- **Scope:** Conventions Git applicables au cycle documentaire et aux évolutions du Framework.
- **Included:** Structuration des changements, historique, branches, commits, tags et intégration des évolutions.
- **Excluded:** Méthodologie générale, planification produit, définitions des concepts, règles d'architecture et automatisation des outils.
- **Authority:** Aucune autorité normative tant que la Reference est Planned ; source canonique des conventions Git uniquement après son activation dans le Documentation Authority Registry.
- **Dependencies:** `MASTER_SPECIFICATION.md` pour l'autorité documentaire ; `Semantic_Reference.md` pour les concepts officiels ; `Methodology_Reference.md` pour la gouvernance des References.
- **Responsibility:** Définir et maintenir les conventions Git sans introduire de règles méthodologiques ou architecturales concurrentes.
- **Activation Criteria:** Charte complète, noyau normatif suffisant pour exercer la responsabilité déclarée, dépendances disponibles et non circulaires, absence de contradiction majeure, Review et Validation réalisées, statut Active dans le Documentation Authority Registry.
