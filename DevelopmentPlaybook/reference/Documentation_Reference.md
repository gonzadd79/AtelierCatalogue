# Documentation Reference

La Documentation Reference déclare le périmètre canonique réservé aux standards documentaires du Framework.

## Reference Charter

- **Status:** Planned
- **Purpose:** Établir et maintenir des standards communs pour produire une documentation claire, cohérente et durable.
- **Scope:** Règles applicables à la rédaction, à la structure, à la présentation et à la maintenance des documents du Framework.
- **Included:** Organisation des documents, conventions éditoriales, informations documentaires attendues, lisibilité et conditions de maintenance.
- **Excluded:** Définitions des concepts, méthodes de travail, architecture du Framework, conventions Git, planification et contenu propre à un projet particulier.
- **Authority:** Aucune autorité normative tant que la Reference est Planned ; source canonique des standards documentaires uniquement après son activation dans le Documentation Authority Registry.
- **Dependencies:** `MASTER_SPECIFICATION.md` pour l'autorité documentaire ; `Semantic_Reference.md` pour les concepts officiels ; `Methodology_Reference.md` pour la gouvernance des References.
- **Responsibility:** Définir et maintenir les standards documentaires sans reproduire les règles appartenant à une autre source canonique.
- **Activation Criteria:** Charte complète, noyau normatif suffisant pour exercer la responsabilité déclarée, dépendances disponibles et non circulaires, absence de contradiction majeure, Review et Validation réalisées, statut Active dans le Documentation Authority Registry.
