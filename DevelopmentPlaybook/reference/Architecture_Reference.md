# Architecture Reference

L'Architecture Reference déclare le périmètre canonique réservé aux règles d'architecture spécialisées du Framework.

## Reference Charter

- **Status:** Planned
- **Purpose:** Établir et maintenir les règles durables qui encadrent l'organisation architecturale du Framework dans le périmètre délégué par sa Constitution.
- **Scope:** Application des principes architecturaux aux structures, responsabilités, frontières et dépendances du Framework.
- **Included:** Règles de structuration, séparation des responsabilités, gestion des frontières et orientation des dépendances.
- **Excluded:** Identité du Framework, modèle constitutionnel d'autorité documentaire, définitions des concepts, contexte propre à chaque Architecture Decision et choix d'implémentation.
- **Authority:** Aucune autorité normative tant que la Reference est Planned ; source canonique des règles d'architecture spécialisées uniquement après son activation dans le Documentation Authority Registry.
- **Dependencies:** `MASTER_SPECIFICATION.md` pour les principes constitutionnels ; `Semantic_Reference.md` pour les concepts officiels ; `Methodology_Reference.md` pour la gouvernance des References.
- **Responsibility:** Définir et maintenir les règles d'architecture spécialisées sans concurrencer la Constitution, le Semantic Reference ou les Architecture Decisions.
- **Activation Criteria:** Charte complète, noyau normatif suffisant pour exercer la responsabilité déclarée, dépendances disponibles et non circulaires, absence de contradiction majeure, Review et Validation réalisées, statut Active dans le Documentation Authority Registry.
