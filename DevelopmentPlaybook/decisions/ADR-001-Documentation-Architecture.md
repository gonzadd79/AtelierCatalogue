# ADR-001 — Architecture documentaire

**Statut :** Accepted

## Décision

`MASTER_SPECIFICATION.md` reste volontairement compact.

Les références détaillées vivent dans des documents spécialisés.

## Rationale

Cette séparation améliore :

- la lisibilité ;
- la maintenance ;
- l'évolutivité ;
- la réutilisation.

## Conséquences

- MASTER décrit.
- References définissent.
- Templates standardisent.
- Examples illustrent.
- Prompts orchestrent.
