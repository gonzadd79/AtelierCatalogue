# Purpose

Cette roadmap est la source canonique de la planification de DevelopmentPlaybook. Elle présente les Epics dans leur ordre d'exécution, consigne les Features terminées et expose les capacités prévues sans décrire leur mise en œuvre.

Les statuts officiels sont `Completed` pour les travaux terminés et `Planned` pour les travaux futurs.

1. **EPIC-001 — Documentation Architecture**
   - Objectif : Mettre en place une architecture documentaire modulaire et durable.
   - Statut : Completed
   - Features terminées :
     - Fondation documentaire du Framework — Completed
     - Architecture documentaire modulaire — Completed
     - ADR-001 — Documentation Architecture — Completed

2. **EPIC-002 — Semantic Reference Foundation**
   - Objectif : Établir la structure du Semantic Reference et définir ses premiers domaines officiels.
   - Statut : Completed
   - Features terminées :
     - Structure officielle du Semantic Reference — Completed
     - Domaine Documentation — Completed
     - Domain Review du domaine Documentation — Completed
     - Domaine Product — Completed
     - Domain Review du domaine Product — Completed

3. **EPIC-003 — Methodology Reference Foundation**
   - Objectif : Établir les premières règles de gouvernance et d'évolution de la connaissance.
   - Statut : Completed
   - Features terminées :
     - Concept Governance — Completed
     - Knowledge Evolution — Completed

4. **EPIC-004 — ADR-002 Migration**
   - Objectif : Appliquer le modèle d'autorité documentaire défini par ADR-002 et aligner les documents concernés.
   - Statut : Completed
   - Features terminées :
     - Création de ADR-002 — Documentation Authority Model — Completed
     - Migration du MASTER_SPECIFICATION en Constitution — Completed
     - Correction de la hiérarchie du Semantic Reference — Completed
     - Audit d'alignement avec ADR-001 et ADR-002 — Completed
     - Réconciliation de la Roadmap avec l'état réel du Framework — Completed

5. **EPIC-005 — Semantic Expansion**
   - Objectif : Étendre progressivement le vocabulaire officiel au-delà des domaines déjà approuvés.
   - Statut : Planned

6. **EPIC-006 — Document Governance**

7. **EPIC-007 — Reference Charters**
