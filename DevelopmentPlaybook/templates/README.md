# Templates

Ce dossier contient les Templates officiels de DevelopmentPlaybook. Ce sont des Derived Assets non normatifs : ils structurent l'application des règles sans les définir ni les remplacer.

Templates disponibles :

- [`Release_Specification.md`](Release_Specification.md) structure la définition d'une Release ;
- [`Certification_Report.md`](Certification_Report.md) structure sa Decision de Certification ;
- [`Publication_Record.md`](Publication_Record.md) structure les faits de Publication.

Leur responsabilité et les règles applicables sont définies exclusivement par le [Release Management](../reference/Methodology_Reference.md#release-management).
