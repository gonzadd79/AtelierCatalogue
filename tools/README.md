# Outils futurs

Ce dossier accueillera uniquement des outils locaux, optionnels et documentés : validateur de données, générateur de miniatures, import assisté, contrôle des liens et de l'intégrité, générateur d'exports et outil de publication.

Aucun outil n'est implémenté dans la fondation. Leur introduction exigera une Story dédiée, une décision sur les dépendances, des entrées/sorties non destructives, une sauvegarde et le maintien de la consultation statique sans installation.
